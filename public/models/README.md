# Слот 3D-модели маскота Charon

Положите файл модели сюда с именем:

```
public/models/charon.glb
```

Сайт подхватит её **автоматически** — без правок кода:

- модель отцентрируется и масштабируется под сцену;
- вокруг неё появятся фирменные орбитальные кольца;
- сохранятся все взаимодействия: реакция на курсор, клик-пульс, плавание.

Пока файла нет, hero показывает фирменное «энергетическое ядро»
(графитовая сфера, визор с глазами и звезда) — подготовленное место
не занимает случайный персонаж.

Рекомендации к модели:
- формат **glTF 2.0 (.glb)**, дракт-сжатие приветствуется;
- размер — желательно до 5–8 МБ;
- материалы: PBR (metallic/roughness) смотрятся лучше всего;
- если в модели есть риг — мягкое покачивание группы уже включено.
