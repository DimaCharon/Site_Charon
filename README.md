# Charon — Personal Digital Identity

[Открыть сайт](https://dimacharon.github.io/Site_Charon/) · Персональное цифровое пространство на русском языке.

Интерактивный знак из обработанного металла, личная identity-карта, семь проектных досье, орбитальный атлас и исследовательские заметки. У концепций явно указан статус. У контактов нет вымышленных адресов.

## Запуск

Нужен **Node.js 20.19+** (для CI используется Node 22).

```sh
npm ci
npm run dev
```

```sh
npm run build        # проверка TypeScript + статическая сборка в dist/
npm run preview      # просмотр проверяемой сборки
npm run standalone   # самостоятельный out/Charon.html, работает без сети
```

## Как пользоваться

- **Объект:** перетаскивание мышью или пальцем. Клавиши-стрелки поворачивают сфокусированную сцену, пробел ставит движение на паузу. Доступны каркасный режим и увеличенный просмотр с экспортом PNG.
- **Профиль:** наведите, коснитесь или выберите направление стрелками клавиатуры, чтобы прочитать описание.
- **Проекты:** горизонтальная прокрутка, свайп или кнопки. «Подробнее о проекте» открывает досье с замыслом, статусом и направлениями работы.
- **My Digital World:** семь пространственных объектов; каждый переключает геометрический этюд и описание в инспекторе.
- **Интересы:** каждая карточка открывает исследовательский вопрос и личную заметку.
- **Настройки:** графитовая/серебряная тема, движения и контур курсора. Системная настройка `prefers-reduced-motion` имеет приоритет.

## Персонализация

**Для всех посетителей** имя и контакты меняются в `public/identity.json`. Повторно опубликуйте файл. Имя отображается отдельным элементом в hero, на identity-карте и в центре атласа.

```json
{
  "name": "Charon",
  "contacts": { "telegram": "", "email": "", "github": "", "social": "" }
}
```

Пустая строка означает «контакт не указан». Email — адрес без `mailto:`; ссылки — полные HTTPS-адреса. Telegram проверяется на домен `t.me`/`telegram.me`, GitHub — на `github.com`.

**Локальный предпросмотр:** шапка → «Настройки пространства» → «Профиль и контакты». Изменения сохраняются только в текущем браузере. «JSON» скачивает конфигурацию для публикации. Кнопка сброса восстанавливает опубликованные данные. Редактор не отправляет данные на сервер.

Контент проектов, интересов и атласа: `src/config/site.ts`. Визуальные токены: `src/styles/global.css`.

### Оригинальный маскот

GLB в комплекте **нет**. Показан отдельный фирменный арт-объект — не замена персонажа другим маскотом. Добавьте оригинал в `public/models/charon.glb` и пересоберите сайт. Поддерживаются встроенные материалы и idle-анимация. [Требования к файлу](public/models/README.md).

## Технологии

React, TypeScript, Vite, Three.js и небольшие SVG-иконки Lucide. Никакого серверного runtime. Рендеринг знака, студийное освещение и шлифованный материал реализованы в Three.js, остальные этюды — параметрические SVG. Шрифты Manrope размещены локально, лицензия прилагается.

```text
src/
  components/   секции, 3D-viewport, модальные окна, настройки и эффекты
  config/       контент, типы, валидация профиля, локальные предпочтения
  scene/        геометрия, материалы, свет и жизненный цикл WebGL
  styles/       базовая система, композиции секций, адаптивность
public/
  art/          оптимизированный WebP-рендер того же объекта
  fonts/        локальные вариативные шрифты: кириллица и латиница
  models/       слот необязательного GLB
  identity.json опубликованные имя и контакты
scripts/        сборка автономного HTML
tests/         браузерные сценарии и аудит доступности
```

## Производительность и доступность

- Текст и WebP-постер отображаются до инициализации WebGL. Трёхмерный движок загружается отдельными чанками, только когда сцена приближается к экрану. На смартфонах и в режиме экономии трафика касание объекта или кнопки «Включить 3D» запускает полноценную сцену по запросу.
- Ограниченный DPR (1.45 на смартфонах, 1.7 на десктопах), цикл до 30 кадров/с. Рендер останавливается вне viewport, в скрытой вкладке и за модальным окном. В статическом режиме кадры рисуются по требованию.
- Студийное HDR-окружение заранее рассчитано и поставляется компактной таблицей отражений; браузер не пересчитывает свёртку освещения при каждом запуске. Нет внешних HDRI, шрифтов, аналитики, API-ключей или CDN. Без WebGL остаются настоящий рендер, контент и навигация.
- SVG-этюды загружаются по видимости, рассчитанная геометрия кэшируется. Изображения ниже первого экрана используют lazy loading.
- Нативные диалоги удерживают фокус, закрываются Escape и возвращают фокус на вызвавший элемент. Есть skip-link, подписи для кнопок и управление с клавиатуры.

## Проверки

```sh
npx playwright install --with-deps chromium
npm run build
npm test
```

Playwright запускает preview автоматически. Покрытие: WebGL, поворот, каркас и PNG-экспорт; все семь проектов и исследовательских заметок; все узлы атласа; редактирование, проверка и экспорт профиля; мобильное меню; ширины 320–1920 px; отсутствие WebGL; reduced motion; автоматические проверки WCAG A/AA в обеих темах. Ошибки JavaScript и сообщения `console.error` делают тест неуспешным.

### Результат проверки выпуска

Шесть браузерных сценариев прошли на production-сборке. Проверены 11 ширин от 320 до 1920 px, а также полноценный автономный HTML с заблокированными HTTP-запросами. В локальном мобильном прогоне Lighthouse 12.8.2: **Performance 92**, **Accessibility 100**, LCP 2,5 с, CLS 0. Это лабораторное измерение, не гарантия скорости на каждом устройстве.

## Публикация

**GitHub Pages:** workflow `.github/workflows/pages.yml` собирает и публикует `dist/` при push в `main`. Источник публикации: Settings → Pages → GitHub Actions. Используется краткоживущая авторизация GitHub Actions, личный токен в проекте не нужен.

**Другой хостинг:** команда `npm ci && npm run build`, выходная папка `dist/`. Относительные пути поддерживают размещение в подпапке. Никаких rewrite-правил для маршрутизации не требуется.

**Один файл:** `npm run standalone` создаёт `out/Charon.html` со встроенными скриптами, стилями, шрифтами, профилем и изображением. Откройте его в современном браузере.
