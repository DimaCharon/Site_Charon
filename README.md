# CHARON — Personal Digital Identity

Персональный сайт-визитка нового поколения: интерактивное цифровое пространство на стыке премиального портфолио и технологичного арт-объекта.

## Что внутри

| Секция | Особенности |
| --- | --- |
| **Hero** | Прелоадер с раскрытием, 3D-маскот Charon (графитовое ядро с визором и звездой), параллакс, magnetic-кнопки |
| **Немного обо мне** | Identity-карточка со сканирующей линией, 6 направлений с анимированными SVG-глифами, манифест |
| **То, что я создаю** | Кинематографичная горизонтальная лента проектов (десктоп), 3D-наклон карточек, честные статусы, детальные диалоги |
| **My Digital World** | Интерактивная 3D-система орбит: 7 узлов-интересов вокруг цифровой идентичности, раскрывающиеся сцены |
| **Интересы** | Асимметричная мозаика 7 карточек с индивидуальными hover-анимациями |
| **Контакты** | Премиальный финальный экран с редактируемыми плейсхолдерами |

Сквозные фичи: кастомный курсор с подписями (отключаемый), маскот-компаньон со состояниями по секциям, светлая/тёмная темы, `prefers-reduced-motion`, lazy-mount 3D-канвасов, адаптив от 360px.

## Стек

- **Next.js 16** (App Router) + **TypeScript**
- **Tailwind CSS 4** — собственная дизайн-система (графит / серебро / холодная лаванда)
- **Three.js + React Three Fiber + Drei** — 3D-маскот и орбитальная система
- **Framer Motion** — хореография интерфейса
- **shadcn/ui** (Dialog, Sonner) — базовые примитивы

## Быстрый старт

```bash
bun install        # или npm install
bun run dev        # http://localhost:3000
```

Продакшен-сборка:

```bash
bun run build && bun run start
```

## Кастомизация

Весь контент — в одном файле:

```
src/config/site.ts
```

- **Имя владельца** — `site.ownerName` (hero-водяной знак, шапка, футер).
- **Контакты** — массив `contacts`. Сейчас там плейсхолдеры: замените `value` и `href` на реальные. Пока `href: null`, кнопка «Написать мне» честно сообщает, что ссылка не задана.
- **Проекты, направления, интересы, узлы мира** — соответствующие массивы в том же файле.

### 3D-маскот

Положите GLB-модель в:

```
public/models/charon.glb
```

Сайт подхватит её автоматически: автоцентрирование, масштаб, орбитальные кольца и все взаимодействия сохранятся. Пока модели нет, показывается фирменное «энергетическое ядро». Подробности — в `public/models/README.md`.

```
└── lib/utils.ts          # cn()
```

## Производительность и доступность

- 3D-канвасы монтируются лениво и ставят `frameloop: never` вне вьюпорта
- DPR ограничен (1.75 / 1.5), точечный свет вместо тяжёлых HDRI (Lightformers рендерятся локально)
- `prefers-reduced-motion` отключает анимации и прелоадер
- Кастомный курсор не активируется на тач-устройствах
- Семантическая разметка, ARIA-метки, клавиатурная навигация
